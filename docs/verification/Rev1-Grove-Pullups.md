# Rev1のR53・R54実装記録（2026-11-24）

この資料は11月24日版の検証記録です。現行版の製造工程と検証結果は[11月25日版の報告](Rev1-DFM.md#2026-11-25-発注用データ)を参照してください。

Groveを追加した時点ではR53・R54を未実装とした。11月24日版では裏面にC23162（4.7 kΩ、0603、Basic）を実装する。R53はJ7のI²Cクロック（SCL）、R54はデータ（SDA）を、それぞれ3.3 Vへプルアップする。

- 当時の回路図からKiCad 10.0.8で出力したネットリストは、R53・R54をともに実装扱いとし、R53はGROVE_SCLと3V3、R54はGROVE_SDAと3V3に接続する。DRC違反・未配線・回路図との不一致は各0件。ERCはエラー0件、警告579件。[Rev1ネットリスト](Rev1-netlist.xml)・[DRC](Rev1-DRC.rpt)・[ERC](Rev1-ERC.rpt)
- 調達BOMと入稿BOMは23品種、KiCadの裏面座標と入稿用CPLは81点。R53は (22.20, −55.08) mm・0°、R54は (35.40, −55.40) mm・180°。裏面ペーストの180開口のうちR53・R54に各2開口。[BOM・CPL照合](Rev1-BOM-check.md)・[DFM](Rev1-DFM.md)
