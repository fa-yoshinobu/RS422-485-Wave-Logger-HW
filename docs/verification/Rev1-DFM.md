## 2026-11-26 JLCDFMの指摘への対応

- ビア3点をR67・R68の裏面ランド外に移した。穴外周から各抵抗の最も近いランドまで、R67の電源ビアは0.466 mm、R68の電源ビアは0.690 mm、R68のSD_DAT1ビアは0.280 mm。WeAct側ランドとの距離が0.06 mmだったR67外形線は片側を省き、残る線の幅を0.15 mmにした。
- J1の1～4番は順に `CH1+ / CH1- / CH2+ / CH2-`。回路図と裏面シルクをLCDのチャネル名に合わせた。5番は回路図でGND、シルクでSG。
- 現行Gerber ZIPのSHA-256は `5363cf0d5a11b0ff5b296a52d215b738d234b72689ac62413c441553523f7d5f`。KiCadのDRC違反・未配線・回路図との不一致は各0件。工場実装74点の位置・回転と裏面ペースト166開口は修正前から同一。現行Gerberを読み込んだJLCDFMの裏面一覧でも参照番号74点が一致した。[現行Gerber](../../pcb/manufacturing/RS422-485-Wave-Logger-Gerber.zip)
- 最終版の基板DFMでパッド内ビアは警告3件から0件、ビア対パッドとシルク対パッドはDanger各1件から0件。SMT DFMの端子―穴近接はDanger 3件から0件になり、全項目のDanger・Warningが各0件。[最終版のPCB・SMT DFMレポート](JLCDFM-2026-11-26.pdf)
- 基板DFMではシルク対穴が89件、挿入ランド対SMDランドが50件のDanger表示。ビアを除く露出した丸穴と長穴をGerberで照合し、シルクとの最小間隔は表0.515 mm、裏0.299 mm。裏面の別ネットまたは無番号の挿入ランドと工場実装ランドの最小間隔は、WeActソケットの無番号ランドとR66.2の0.239 mm。信号付きランドとの最小はF14とR66.2の0.299 mm。レジストブリッジは0件。ソケット周辺のこて先の作業性は試作時に確認する。
