# Wave Logger Rev.1 基板配置と取付寸法

100 × 100 mm、2層、板厚1.6 mm。原点は表面から見た奥左で、xは右、yは手前に増える。奥側で配線を接続し、手前で液晶とエンコーダを操作する。裏面図は基板を裏返した向き。[表面配置図](PCB-front.png)・[裏面配置図](PCB-back.png)・[3D図](../enclosure/drawings/PCBA_Front.png)

| 位置 | 搭載物と向き |
| --- | --- |
| 奥の縁 | 左からJ1（RS-422/485）、J6（絶縁CAN）、J4（12 Vセンタープラス）。電線とDCプラグは奥から挿入する。J1・J6はいずれも表から見て左が1番。結線順は表面の端子台の右脇、個別のピン名は各端子の真裏に印刷。 |
| 奥左 | J1の手前にU7・U6（DIP-8）、J1近くの裏面にSW1（RS用4連DIP）。SM712・SP3485・受動部品は裏面。TP7とTP8はアンプのそばから表面で測定できる。 |
| 奥中央 | J6、F2、PS2、C27、裏面SW2（CAN用2連DIP）、TP11、TP12がCAN側。U8は裏面で絶縁境界をまたぐ。 |
| 中央左 | WeActのUSB-Cは左側面。P5（SWD/UART）はWeAct本体に取り付け、左側面から接続する。母基板には外周ソケット用に2列×15ピンを2組（計60穴）設け、RX1（PA9）・RX2（PA10）・GNDはこの外周ソケットで接続する。裏面のmicroSDは右へ引き出す。x=30～56、y=25～48 mmをカード通路としてソケット以外の表面部品を避け、WeAct自体を除く表面部品の侵入をKiCadルールでも検出する。 |
| 中央右 | J4からF1、D3、PS1、Q1、U5へ給電する。PS1とC18は表、整流・切替・3.3 V電源のSMDは裏。TP2～TP5は液晶の奥側から測定できる。 |
| 手前 | J2は8.5 mmの12ピンソケットに横向きで実装。液晶が左、EC11の中心は右の (85.0, 68.15) mm。RTC保持用のC26は液晶下の (60.0, 69.0) mm に手はんだする。正極は左の角パッド。12個のテストポイントは表から測定できる。 |

WeActの右、液晶の奥にある表面シルクで、製品名・通信規格・版数・設計者・設計日を確認できる。裏面のGrove各口には用途と3.3 Vを表示した。C26（表）とC15（裏）は部品外形の外にある `+` で正極を照合できる。[表裏のシルク確認図](verification/Rev1-silkscreen.png)

### 裏面スイッチと拡張用コネクタ

表面から見た座標で、SW1（RS用4連、OTAX KHS42E）の中心は (6.50, 11.75) mm、SW2（絶縁CAN用2連、KHS22E）は (75.00, 6.20) mm。いずれも裏面実装。通常の測定時は全極OFFにする。試験回線ではSW1の1・2をCH1用、3・4をCH2用として対で操作する。SW2の1はCAN終端121 Ω、2は未接続。2個とも裏面で手はんだし、ケース底の2つの開口から設定する。[底面から見たスイッチとケース図面](../enclosure/drawings/Assembly.md)・[KHSシリーズ寸法・手はんだ条件](https://akizukidenshi.com/goodsaffix/KHS.pdf)

Groveは両口とも3.3 V。液晶下の手前縁で挿入口を +Y に向け、端面を y = 100.00 mm に合わせた。ケース正面に各18 mm幅の開口を設けた。モデル上、コネクタ上面から液晶基板下面までは両口とも6.04 mm。ケーブル公称断面と指先を仮定した空間はケース外から挿入口まで通る。ラッチを指のみで完全に解除できるかは実物未確認。[Grove正面図](../enclosure/drawings/Grove-front.png)・[操作空間の寸法](../enclosure/drawings/Assembly.md)

## 現行Rev.1の配置と配線

J1側を奥にして、表面の液晶下にCH1・CH2のリード抵抗を並べた。300 Ω・1 WはR40・R41・R43・R44、240 Ω・¼ WはR39・R42・R63・R64。8本は横置きで実装してから液晶を取り付ける。裏面のR1～R8・R55～R62は0805手はんだ。枠付きのシルク `INPUT RESISTOR MAP / J1 EDGE` は、J1側を上にして裏側から見た相対位置を表す。[表面配置](PCB-front.png)・[裏面配置](PCB-back.png)・[表裏の銅箔パターン](Rev1-copper.pdf)

D7・D8の1番はカソードで、シルクの帯とKを合わせる。D7の1番からR40へ、D8の1番からR43へ配線した。R46・R65は絶縁CAN側で直列。現行の工場実装は裏面74点。基板外形、取付穴、端子台、スイッチ、液晶ソケットの位置は11月24日版と同じ。[現行の入稿ファイル](Rev1-order-estimate.md#入稿ファイル)

## 11月24日版の配線と製造記録

以下は11月24日版で測定した数値。11月25日版のビア数、GNDの接続状況、絶縁距離、工場実装点数は[発注用データの検査結果](verification/Rev1-DFM.md#2026-11-25-発注用データ)を参照する。

- Grove信号の配線幅は0.25 mm、3V3は0.40 mm。J7・J8の4番は0.50 mm幅のサーマルで本体GNDベタに接続した。WeAct周辺の既設GNDを3区間だけ引き直し、既存信号の銅箔を維持した。R1～R4のランドからGrove信号までの最短は5.826 mm。R1～R4からアンプへ向かう入力線とGrove信号の平面上の交差は0か所。入力抵抗から離れたP1−・P2+の分岐とは、表裏の別層で計3か所交差する。[製造性と絶縁距離の検証](verification/Rev1-DFM.md)

- J8_IO1と差動アンプの基準電圧MID_1V65の間隔は、同一層の配線間で最小2.250 mm、ビア・ランドを含め最小2.075 mm。KiCadのカスタムDRCでもこの2ネットに2.00 mmの最小離隔を指定した。Grove GPIOとアナログ信号の40組で、同層・縁間1 mm未満・角度差5°以内の並走は0か所。[測定結果](verification/Rev1-DFM.md)
- KiCad 10.0.8でベタを再充填し、Groveを含む確定3シートと照合した。DRC違反0件、未配線0件、回路図との不一致0件。この時点ではQ3・R47・J5・D7を搭載していなかった。F35～F38はR49～R52を経由してJ7・J8へ配線した。[DRC結果](verification/Rev1-DRC.rpt)
- OUT1のU6.1→R19.1は2.35 mm、R19.2→PA6は6.06 mm。OUT2のU7.1→R20.1は1.89 mm、R20.2→PB1は7.43 mm。値はパッド間の水平投影配線長。OUT1・OUT2・ADC1_IN・ADC2_INでは、他の信号と同一層・銅箔縁間1 mm以内・角度差5°以内で0.5 mmを超える並走は0か所。
- 12 V・5 V・CANバス電源の9ネットは配線幅0.50 mm。
- パスコンの電源パッドから対象ピンまでの直線距離は、C1→U2.8が1.99 mm、C2→U3.8が1.88、C3→U6.8が1.91、C4→U7.8が3.68、C5→U5出力が2.53、C6→J2.2が2.15。C29→U8.7は2.45、C30→U8.13は2.35、C28→PS2出力は2.51、C13→Q1ソースは2.60 mm。C5とC15の出力側パッド間は2.01 mm。
- JLCPCB Economicは裏面81点・23品種。R53・R54も裏面に実装する。裏面のU8・C15・SW1・SW2は手はんだ。表の挿入部品・モジュール16点とTP12か所もCPLから除外した。[BOM照合表](verification/Rev1-BOM-check.md)・[実装座標](../pcb/manufacturing/back-pos.csv)
- 発注指定は緑レジスト、有鉛HASL。Gerber ZIPに表裏の銅箔・レジスト・シルク、裏面ペースト、外形、めっき・非めっきドリル、Gerberジョブを収録した。外形加工の基準となる線の中心間は100.000 × 100.000 mm。KiCadのジョブファイルのSizeは線幅0.05 mmを含む100.05 × 100.05 mm。裏面ペーストはCPLと同じ81点に対応し、R53・R54の各2パッドを含めて180開口。裏面で手はんだするU8・C15・SW1・SW2にはペースト開口を設けていない。[製造データ](../pcb/manufacturing/RS422-485-Wave-Logger-Gerber.zip)

### MID配線とGNDベタの補強

MID_1V65を165.92 mmから135.00 mmに短縮し、RX1・RX2・TX1との1 mm未満の同層並走を解消した。TX2・DE2の並走と、一部の層切り替えで1.5 mm以内にGNDビアを配置できない箇所が残る。本体GNDビアを外周・液晶の下・ベタの分割片に99個追加した。表裏ともベタのある位置を2 mm格子で確認し、最寄りGNDビアまたはGNDスルーホールから最長7.96 mmだった。CAN側と本体側の銅箔間隔は表5.899 mm、裏4.000 mm。[修正前後の銅箔図](verification/Rev1-noise-GND.png)・[測定内訳](verification/Rev1-DFM.md)

### 表面ベタ追加時の検証記録

従来は裏面だけにベタがあり、液晶クロックとデータ線の下に広い空白があった。表面にも本体GNDと絶縁CANのV−をそれぞれ設け、本体側に36個、CAN側に2個のビアを追加して表裏を接続した。ADC1入力の反対面には幅0.25 mmのGND配線を計4.58 mm追加した。部品の位置と信号配線は従来どおり。表裏のベタはすべて各系統のGNDに接続され、CANの絶縁境界とU8直下の銅箔禁止帯にはベタが入っていない。[修正前後の銅箔分布図](verification/Rev1-ground-planes.png)
